# ebtihaj-khan.github.io

Personal resume site for Ebtihaj Khan, technical product manager.

The site is plain HTML, CSS, and JavaScript. It has no build step.

- `index.html` holds all resume content.
- `assets/styles.css` holds the design tokens, layout, and print styles.
- `assets/orb.js` draws the hero orb on a canvas.
- `assets/main.js` runs the integration map, filters, theme, and command menu.

To preview locally, run `python3 -m http.server` in this folder and open `http://localhost:8000`.

GitHub Pages serves the `main` branch from the repository root.
